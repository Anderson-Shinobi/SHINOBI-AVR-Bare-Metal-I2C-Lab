# SHINOBI AVR Bare-Metal I²C/TWI Lab

**From Physics to Firmware · SHINOBI Engineering**

ATmega328P register-level TWI controller with DS1307 at 0x68, START/repeated START/STOP, ACK/NACK and Wokwi capture.

> **Status:** firmware prepared; AVR-GCC CI and Wokwi/VCD protocol validation pending. Simulated or physical measurements are not claimed.

This repository is an independent engineering laboratory linked to the [SHINOBI Engineering portfolio](https://anderson-shinobi.github.io/). The laboratory's full source, wiring, MIT license and automated checks will be delivered in a development branch.
